# HANARU 진행 상황 (새 세션 인수인계용)

베트남 유학생·유학 준비생(D-2, D-4)용 입국·비자 챗봇 데모. 대표 이원희. 사업 방향 전환이 아닌 작은 검증용 데모.

## 핵심 원칙 (대표 결정)
- 친구처럼 쉽게, 하나씩 묻고 답한다. 답은 베트남어 먼저, 한국어 아래(병기)
- **틀린 말 금지**: 규정 카드(`kb/cards.json`)에 있는 내용만. 숫자(알바 시간, 재정 금액, 학교 등급)는 `lib/rules.ts` 결정적 함수로만
- 공관(하노이·호치민·다낭)별로 다르면 공관별 내용을 각각 안내
- 졸업증명서 영사확인: 하노이·호치민 기준 "사증 접수일로부터 1년 이내"
- 교환·방문 체재비: 공관별 금액 각각, "매년 갱신" 안내 (2025년 주거급여 기준)
- 전문학사 한국어 기준(P20)은 "확인 필요", 지급유보방식 잔고증명서는 "법무부 매뉴얼 확인" 안내
- 개편 예정(2026.10.7 법무부 발표, R 카드)은 현행처럼 말하지 않는다
- 서식은 초안만 만들고 제출·대행하지 않는다(행정사법). 개인정보는 서버에 저장하지 않는다
- 모델: Claude Opus 5.5 (`claude-opus-5-5`), 채점: Claude Haiku 5.5

## 개발 메모
- 클라우드 세션에서는 키가 `MY_ANTHROPIC_API_KEY`로 등록돼 있어 `ANTHROPIC_API_KEY="$MY_ANTHROPIC_API_KEY" npm run eval`로 실행
- 시범 비용: 첫 문항이 캐시 생성으로 약 $0.24, 이후 문항당 $0.02~0.03, 채점은 무시할 수준
- 이 개발 환경에는 다른 용도의 `ANTHROPIC_BASE_URL`이 있어서, `lib/anthropic.ts`가 공식 주소를 고정한다
- npm 설치 오류(edgesOut) 때문에 `.npmrc`에 `legacy-peer-deps=true`
- 지식 베이스 원본: `kb/source/` (`python3 kb/source/build.py`로 검사·생성)
