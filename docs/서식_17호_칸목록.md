# 사증발급신청서(별지 제17호서식) 칸 목록 — 1단계 검토용

- 기준 서식: 한국어-베트남어판(KR-VN, 5쪽, 2022.02.07 개정). 한국어-영어판과 문항 번호·구성 같음(1.1~11.1, 12 서약)
- 목적: 입력 웹페이지(`/form/visa`)에서 받을 칸과 PDF에 들어갈 위치를 정하기 위한 목록. 대표 검토 후 2단계(화면·PDF) 진행
- 원칙: 입력값은 학생 브라우저에만 저장, 서버 전송·AI 사용 없음. 학생이 입력한 내용만 옮기고 작성 조언은 하지 않음(행정사법). 서명란은 비움

## 표 읽는 법
- **입력**: 글 = 한 줄 글자, 날짜 = 달력 선택, 선택 = 서식의 [ ] 체크 항목 중 하나, 표 = 여러 줄 입력
- **필수**: ● 서식상 모두 답해야 함(신청서 작성방법: "모든 질문에 답변"), ○ 조건부(앞 문항이 '예'/'기혼' 등일 때만), – 학생이 쓰지 않음
- **자동**: 앱이 미리 채우거나 변환하는 것. 학생이 언제든 고칠 수 있음
- **칸 크기**: PDF 칸의 대략적인 너비(쪽 너비 대비). 긴 글은 아래 "긴 글 자동 맞춤" 규칙 적용

## 입력 규칙 (서식 '신청서 작성방법' 기준)
- 모든 답은 **한글 또는 영문**. 베트남어 성조 문자(ă, ơ, đ, ̀ 등)가 들어가면 경고
- 이름(1.1, 1.8, 5.2, 4.5 등)은 여권처럼 **영문 대문자**로 자동 변환(Nguyễn Văn Đức → NGUYEN VAN DUC)
- '기타'·'예'를 고르면 상세 칸이 열림(서식: "'기타'를 선택한 경우 상세내용 기재")

## 긴 글 자동 맞춤 (2단계 구현 규칙)
1. 기본 글자 크기 9pt로 칸에 넣어 본다
2. 넘치면 글자를 0.5pt씩 줄인다(최소 6.5pt — 출력했을 때 읽을 수 있는 크기)
3. 그래도 넘치고 칸 높이가 두 줄을 넣을 만하면 두 줄로 나눠 다시 9pt부터 줄인다(주소 칸 등)
4. 그래도 넘치면 칸에는 앞부분과 "(별지 참조 / Xem tờ rời)"를 넣고, 전체 내용을 **별지 페이지**에 번호와 함께 싣는다. 서식 유의사항 1("자세한 내용은 별지로 작성 가능")에 따른 방법
5. 표 문항(8.6~8.9, 11.1)이 서식 줄 수를 넘으면 넘는 줄을 별지 표로 싣는다
6. 입력 화면에서는 칸마다 "칸에 딱 맞음 / 작게 들어감 / 별지로 넘어감"을 실시간으로 보여 준다

## 대표님 결정 사항
1. **주소 등 베트남어 고유명사의 성조 제거**: 서식은 한글 또는 영문만 허용. 주소(4.1, 6.3 등)를 "So 12, Duong Le Loi, Quan 1, TP Ho Chi Minh"처럼 성조 없는 로마자로 자동 변환해도 되는지
2. **날짜 형식**: 1.4는 서식에 yyyy/mm/dd로 적혀 있고, 8.6·8.7 방문기간은 베트남어판 표 머리에 "Ngày tháng năm"(일/월/년) 순서로 적혀 있음. 칸마다 서식 머리글 순서를 따를지, 전부 yyyy/mm/dd로 통일할지
3. **11.1 작성 도움 여부**: HANARU로 초안을 만든 것이 '다른 사람의 도움'에 해당하는지는 앱이 판단하지 않고 학생이 직접 고르게 할 계획. 이 문항 옆에 보여 줄 문구가 필요하면 정해 주세요(예: "사실대로 답하세요. 궁금하면 신청할 공관에 문의")
4. **기본값**: 국적·출생국가·여권 발급국가 = VIETNAM, 여권종류 = 일반, 입국목적 = 유학·연수, 신청일자 = 오늘. 이 외에는 기본값 없음. 괜찮은지
5. **사진**: 사진 이미지를 올려 PDF에 넣는 기능은 빼고(공관 규격·실물 부착), 빈칸으로 둘 계획. 괜찮은지
