# 지식 베이스 원본

규정 카드와 평가 질문의 원본입니다. 수정은 여기서 하고, 아래 명령으로 검사와 생성을 합니다.

```bash
python3 kb/source/build.py
```

| 파일 | 내용 |
|---|---|
| `sources.py` | 출처 목록(S1~S14)과 카드 상태 정의 |
| `cards.py` | 규정 카드 56장 |
| `evalset.py` | 평가 질문 67개 |
| `build.py` | 출처·카드 연결, 학교 명단 수, 평가 질문의 학교 정답을 검사하고 `kb/cards.json`, `kb/eval.json`, `kb/검토용_규정카드_초안.md`를 만든다 |

`kb/universities.json`(2025년 인증대학 명단)은 원문에서 직접 정리한 파일입니다.
근거 원문(매뉴얼 PDF, 공관 안내문 등)은 저장소에 넣지 않았습니다.
